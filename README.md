# Dashboard de Producción – Power BI

Este proyecto muestra un dashboard interactivo hecho en Power BI para monitorear el desempeño de producción.

## 📊 Características

- KPIs: Producción total, OEE, cumplimiento
- Filtros por fecha, línea, turno
- Visualizaciones dinámicas
- Actualización automática desde Excel

## 📁 Archivos

- `Dashboard_Producción_Mayo_2025.pbix` – archivo editable de Power BI
- `captura_dashboard.png` – imagen de muestra

## 🛠️ Herramientas utilizadas

- Power BI Desktop
- Excel (fuente de datos)
